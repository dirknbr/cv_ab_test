# CV AB test with Gemini

Given the prevalence of AI in recruitment and challenges around it,
this is a small exercise to get an LLM to compare two CVs and choose the better
one given the job spec.

I think comparison of two CVs are more meaningful vs an absolute comparison.

You could use this to tell you which version of a CV for the same person is better.

Test data: the job spec is a real one, while the 2 CVs are AI generated.

## How to use it

Save CVs and job spec in text files and then run `ab_test.py`.
